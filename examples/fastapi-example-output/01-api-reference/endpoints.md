## Endpoint Details

### POST /auth/token

Issue a JWT access token using username and password credentials.

**Authentication:** None

**Request:** `application/x-www-form-urlencoded`

| Field | Type | Required | Description |
|-------|------|:--------:|-------------|
| `username` | string | Yes | The user's login name |
| `password` | string | Yes | The user's plaintext password (hashed with bcrypt before comparison) |

**Response `200 OK`:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

**Error Responses:**

| Status | Detail | Trigger |
|--------|--------|---------|
| `401 Unauthorized` | `"Incorrect username or password"` | Credentials do not match any user |

### GET /tasks

Return all tasks belonging to the authenticated user. Tasks from other users are never returned.

**Authentication:** Bearer JWT required

**Query Parameters:** None

> 🔴 **docpilot note:** No pagination, filtering, or sorting parameters were found in the route handler. With a large task list this endpoint returns all rows. Confirm whether pagination is planned or intentionally omitted.

**Response `200 OK`:** Array of `TaskResponse` objects (see [data-models.md](./data-models.md))

```json
[
  {
    "id": 1,
    "title": "Write unit tests",
    "description": "Cover the auth module",
    "status": "in_progress",
    "owner_id": 3,
    "created_at": "2026-05-28T09:14:22.000Z",
    "updated_at": "2026-05-30T11:00:00.000Z"
  }
]
```

**Error Responses:**

| Status | Detail | Trigger |
|--------|--------|---------|
| `401 Unauthorized` | `"Could not validate credentials"` | Missing or invalid JWT |

### POST /tasks

Create a new task. The `owner_id` is set automatically from the JWT — clients do not supply it.

**Authentication:** Bearer JWT required

**Request:** `application/json` — `TaskCreate` schema

| Field | Type | Required | Default | Description |
|-------|------|:--------:|---------|-------------|
| `title` | string | Yes | — | Short title of the task |
| `description` | string | No | `null` | Optional longer description |
| `status` | `TaskStatus` | No | `"pending"` | Initial status |

**Example Request Body:**
```json
{
  "title": "Deploy to staging",
  "description": "Run smoke tests after deploy",
  "status": "pending"
}
```

**Response `201 Created`:** `TaskResponse` object

**Error Responses:**

| Status | Detail | Trigger |
|--------|--------|---------|
| `401 Unauthorized` | `"Could not validate credentials"` | Missing or invalid JWT |
| `422 Unprocessable Entity` | Pydantic validation error detail | `title` missing or invalid `status` value |

### PUT /tasks/{id}

Update one or more fields of an existing task. Follows partial-update semantics — only supplied fields are changed.

**Authentication:** Bearer JWT required

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | integer | The task's primary key |

**Request:** `application/json` — `TaskUpdate` schema (all fields optional)

| Field | Type | Required | Description |
|-------|------|:--------:|-------------|
| `title` | string | No | New title |
| `description` | string | No | New description |
| `status` | `TaskStatus` | No | New status value |

**Example Request Body:**
```json
{
  "status": "done"
}
```

**Response `200 OK`:** Updated `TaskResponse` object

**Error Responses:**

| Status | Detail | Trigger |
|--------|--------|---------|
| `401 Unauthorized` | `"Could not validate credentials"` | Missing or invalid JWT |
| `403 Forbidden` | `"Not enough permissions"` | Task exists but belongs to a different user |
| `404 Not Found` | `"Task not found"` | No task with the given ID exists |
| `422 Unprocessable Entity` | Pydantic validation error detail | Invalid `status` value |

> 🔴 **docpilot note:** The distinction between 403 and 404 behavior when a task ID exists but belongs to another user could not be confirmed from schema alone. Some implementations return 404 in both cases to avoid leaking resource existence. Verify the actual behavior in `routers/tasks.py`.

### DELETE /tasks/{id}

Permanently delete a task. This operation is not reversible.

**Authentication:** Bearer JWT required

**Path Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | integer | The task's primary key |

**Request Body:** None

**Response `204 No Content`:** Empty body

**Error Responses:**

| Status | Detail | Trigger |
|--------|--------|---------|
| `401 Unauthorized` | `"Could not validate credentials"` | Missing or invalid JWT |
| `403 Forbidden` | `"Not enough permissions"` | Task belongs to a different user |
| `404 Not Found` | `"Task not found"` | No task with the given ID exists |
